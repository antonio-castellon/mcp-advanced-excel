# Security

Do not paste tokens, keys, or other secrets into an issue, a comment, or a commit.

Report a vulnerability in private, on the Security tab of this repository (Advisories), not in an open issue. Say the package version and the MCP client. Do not include secrets.

The read model (allowlists, stdio only, no formula evaluation) is described in [docs/SECURITY.md](docs/SECURITY.md).
